# 无服务器：课表数据只存在设备本地

## 背景与决定

使用者是本校同学（几十到几百人量级），课表数据一学期变不了几次，且天生可以离线。因此 v0.1 不做账号体系、不做后端、不做云同步：数据只存在设备本地的数据库里。

## 理由与代价

没有服务器意味着没有 ICP 备案、没有运维、没有成本，同学装上就能用。代价有两个：换设备需要迁移，同学之间无法直接查看彼此的课表（教务系统本身也不允许查别人的课表）。这两件事都由**导出 / 导入课表文件**覆盖——顺带得到"分享课表"这个功能。

## 注意：分享会泄露学号

教务系统导出的课表文件里含有**学号、姓名、班级**。分享功能必须在导出时剥离或替换掉这些字段，否则一次分享等于公开自己的学号。这不是可选项，是分享功能的前置条件。
