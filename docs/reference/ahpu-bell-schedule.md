## 仍未核实的两格

第四节→第五节的 5 分钟课间、以及第五节 12:20 结束，是由"8:00 上课 + 45 分钟一节 + 课间 5 分钟 + 9:35 之后 9:55 才上课"推算出来的，使用者未逐格确认。数据自洽，但若要精确到分钟，值得再核一次。
