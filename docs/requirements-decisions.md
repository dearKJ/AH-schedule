# 需求访谈遗留决定

2026-09 的一次需求访谈产出了三十余项决定。其中一部分已经写进 [`README.md`](../README.md)、[`CONTEXT.md`](../CONTEXT.md)、[`docs/adr/`](adr/) 和 [`docs/reference/`](reference/)；**本文件收录剩下的那一部分**——它们此前只存在于对话记录里，没有任何版本控制兜底。

已落盘的内容不在此重复。写 spec 时，本文件的每一条都应被收进规格或重新分派到它该去的地方。

---

## 1. 导入的语义

- 交互是**选文件**（手机浏览器下载的 `.xls`，或电脑导出后传手机）。**明确不做**粘贴文本导入——理由是：用 Excel/WPS 打开该文件再复制，HTML 里的 `<br>` 分组会被破坏，解析反而更脆，还得额外写一套粘贴解析。
- **重新导入 = 整学期覆盖，不合并**。依据是教务系统每次导出的都是全量。
- 导入预览页必须**明说会替换**，并**警告使用者手动标记的例外将被清除**（v0.1 不做例外保留；保留例外是 v0.2 的事）。
- 预览页是**必需品而非锦上添花**：教务系统模板自身有 bug（见 [`docs/reference/ahpu-jwxt-export-format.md`](reference/ahpu-jwxt-export-format.md) 第五节），解析器迟早会碰到没见过的写法，**静默失败是最糟的结果**。

## 2. 冲突的显示

- 先区分两件事：同一格里"**周次错开**"的多门课是**常态**（样例课表里就有）；**同一格 + 同一周 + 两门课**才是冲突。
- 冲突时：**并排显示并标红**，详情里列出冲突双方，**不自动取舍**。
- 理由：教务系统本不该产生这种数据，一旦出现就意味着"解析出错"或"教务系统改课表改出了重叠"——这是**需要人眼介入的信号**。静默吞掉其中一门，使用者可能一学期后才发现某门课从没被提醒过。

## 3. 测试夹具与隐私

- 导入解析的单元测试**必须拿使用者的真实导出文件当夹具**。教务系统模板有 bug（少写一个右括号、空格分隔的断档周、停课单列一条），**编造的样本锁不住这些坑**。
- **但那份文件含使用者的学号、姓名、班级，而本仓库是 public。入库前必须先脱敏**（替换成假值），且脱敏结果要**给使用者过目**。这是硬约束，不是建议。
- 原始样本留在使用者的下载目录（`D:\_Network_download\课表.xls`），**不要提交它**。

## 4. 导出的格式

- 自定义 JSON，**带版本号**（便于以后升级而不破坏旧文件）。
- 导出时**剥离学号 / 姓名 / 班级**——这是 [ADR-0002](adr/0002-local-only-storage.md) 的前置条件，不是可选项。
- **不做** `.ics`：iCalendar 表达不了单双周、断档周、停课例外，硬塞会丢信息。

## 5. 六条被默认的假设

访谈中默认成立、但使用者没有逐条表态。**任何一条不成立，都会改变实现**，所以值得在 spec 里逐条确认一次。

1. 一周从**周一**算起。
2. 学期总周数**不写死**：周次导航以数据实际范围为准，另留一个可配置的总周数。（样例课表最远排到第 18 周。）
3. 导入 = 整学期覆盖，不合并。
4. 第 N 周 = 从开学那周的周一算起的连续 7 天。
5. 只处理**学生课表**，不含教师课表 / 班级课表。
6. 课程颜色在本地**按课程稳定分配**（不入库、不上云）。

## 6. 被否掉的选项与理由

理由是这张表的主要价值：**没有理由，以后总会有人把它们"修"回来。**

| 否掉的 | 换成的 | 理由 |
| --- | --- | --- |
| Kotlin 原生 | Flutter | 使用者的目标之一是学新技术；并保留日后开 iOS 的退路（[ADR-0003](adr/0003-flutter-android-only-v0-1.md)） |
| 自动登录抓取教务系统 | 读导出文件 | **不是"难"，而是要在 App 里存使用者的教务系统密码**，而 App 是要发给同学的 |
| 粘贴文本导入 | 选文件 | 复制会破坏 `<br>` 分组 |
| `.ics` 导出 | 自定义 JSON | iCalendar 表达不了单双周 / 断档周 / 停课 |
| 服务器 + 账号 + 云同步 | 纯本地 | 免备案、免运维、免成本；代价由导出/导入覆盖（[ADR-0002](adr/0002-local-only-storage.md)） |
| Provider / Bloc | Riverpod | Bloc 对单人项目样板代码翻倍 |
| sqflite / Hive / Isar | drift | sqflite 太裸，要手写 SQL 字符串；Hive/Isar 是键值模型，不适合"按学期、按周次查询" |
| 先建课程库再刷到网格 | 长按空格子直接加 | 省掉一套课程管理界面，留到 v0.2 |
| 一屏只显示几天（日历式） | 一屏尽收整周 | 课表的价值就是一眼看全周；日历式每天要多点两次屏幕 |
| 为 iOS 做假设性工作 | 冻结 `ios/` 目录 | 没有 Mac，那些配置只会空转（[ADR-0003](adr/0003-flutter-android-only-v0-1.md)） |

## 7. 尚未确定的事实

- **使用者当前处于第几教学周。** 教务系统导出的文件里**没有学期起止日期**，而"高亮今天"、桌面小组件、上课提醒全都需要它。按已定方案这是**运行期数据**——使用者在 App 里填"第 1 周的第一天"——因此**不阻塞 spec**，但内置默认值目前空缺。
- 学期总周数同样未知（见第 5 节第 2 条）。
- 使用者去教务系统的"选择教学周"下拉框看一眼即可确定，尚未查。

## 8. 仓库工作方式

- **单人项目，直接提交 `main`，不开分支。**
- 只在明确要求时提交；不主动 push。
- 中文交流。使用者回答极简，**给强推荐 + 一两句理由**比给开放式问题有效得多。
